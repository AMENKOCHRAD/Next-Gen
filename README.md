# SPORTIFY - Salle de Sport Virtuelle (JavaFX)

[![Java](https://img.shields.io/badge/Java-17-%23ED8B00.svg?logo=java)](https://www.java.com/)
[![JavaFX](https://img.shields.io/badge/JavaFX-19-%23258BD9.svg)](https://openjfx.io/)
[![IntelliJ](https://img.shields.io/badge/IDE-IntelliJ_IDEA-%23000000.svg?logo=intellij-idea)](https://www.jetbrains.com/idea/)

SPORTIFY est une application desktop de salle de sport virtuelle développée avec JavaFX offrant :

- 🏋️‍♂️ Cours et programmes d'entraînement
- 🤖 Exercices guidés avec analyse de mouvement
- 📅 Gestion d'événements sportifs
- 🛍 Boutique d'équipements sportifs
- 🥗 Plans nutritionnels personnalisés
- 📊 Suivi des performances

## Technologies

### Core
- **Java 17** (LTS)
- **JavaFX 19** (Interface graphique)
- **Maven** (Gestion des dépendances)

### Données
- **MySQL** (Base de données)
- **JSON** (Échange de données)

### Outils
- **IntelliJ IDEA** (IDE principal)
- **Scene Builder** (Création d'interfaces)
- **Python** (Analyse de mouvement IA)

## Installation

### Prérequis
- JDK 17+
- JavaFX SDK 19
- Maven 3.8+
- MySQL 8.0+
